Add a software pattern normalization rule
 Release version: Brazil 
 Updated November 5, 2026 
 1 minute to read
 You can add a pattern normalization rule to normalize specific software products in
 your environment based on a common pattern.
 Before you begin
Role required: sam_admin 
 About this task
 Note: When creating a pattern normalization rule for custom products and publishers,
 create the custom product and company records first.
 Procedure
 Navigate to All > Software Asset > Administration > Pattern Normalization Rules and create a new record (see table for field descriptions). 
 Table 1. Pattern Normalization Rule form 
 Field

 Specify a unique name for pattern normalization
 rule.

 field. 
 Discovered product contains 
 Specify text to search for in the product field. 
 Active 
 Option that activates the rule. 
 Discovered publisher is empty

 publisher field (the rule applies to discovery models where
